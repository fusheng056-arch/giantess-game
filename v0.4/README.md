# v0.3 3D scale blockout (Three.js r160 via unpkg importmap)
Run through any static server (textures cannot load from file://): `cd v0.3_3d && python3 -m http.server 8123` -> http://localhost:8123/index.html
Easy-swap config blocks at the top of the script: SPRITE_CFG (character sheets), PROPS (prop art), CG_SLOTS/CG_DIR (defeat CGs), QUAL, CAM, SPAWNS.
