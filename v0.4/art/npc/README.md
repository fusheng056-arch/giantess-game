# Shrunken NPC + hero sprites (draft, pass 2)
Scale 16 px = 1 cm; each character is 1 cm tall -> 16x16 frames.
Generated by `make_npcs.py` (hand-placed pixels in Python; re-run to regenerate all files + preview).

Per character:
- `*_walk.png` 32x64: rows = down, left, right, up; columns = frame 1, 2. Frame 2 has a 1 px body bob (head/torso drop 1 px, feet planted).
- `*_panic.png` 16x16: facing down, smaller head, arms raised, hands clearly above head.

Characters: hero (redraw from hero_sheet_v1: messy dark-brown hair, dark grey zip hoodie with visible hood edge, white tee at the front, darker grey trousers, black sneakers;
files `hero_walk.png` / `hero_panic.png`; the original ../hero.png is untouched),
chentianming 陈天明 (spiky black hair, orange T-shirt), yeyifan 叶依凡 (brown shoulder-length hair, white blouse, pleated navy skirt),
zhangtao 张涛 (glasses, grey suit, red tie, greying temples, 2-3 px light grey each side, visible from behind), redgirl (ponytail, red dress), oldman (grey beard, cane).

Side views are drawn separately for left and right (not mirrored): the old man's cane stays in his right hand
(in front of the body facing left, behind it facing right), and the ponytail and hair tie are drawn per side view so they always hang at the back of the head.

Rules: hard pixels, binary alpha (0/255), 10-12 colours per character (<=16), transparent, no shadows, dark outline.
`_preview.png` = labelled contact sheet at x6.
